0. 저장형 게임의 Verse8 설계 규칙 (공식 문서 기준)

확인 출처 — docs.verse8.io/ko/docs 직접 조회.
  • 세이브는 반드시 Global User State. @verse8/local-cache 문서는 "player state data like progress or inventory"에 사용 금지를 명시(스토리지 압박 시 언제든 삭제됨). 저장형 게임에서 Local Cache는 세이브 저장소가 될 수 없고, 지형 청크·디코딩 에셋 같은 재생성 가능한 파생 데이터 캐시로만 쓸 수 있음.
  • 저장 빈도 설계 필수. server.remoteFunction() 표준 호출이 약 10회/초 제한. 저장형은 매 클릭마다 저장하면 안 되고, ①30~60초 주기 오토세이브 ②화면 전환·건설 완료 같은 의미 있는 체크포인트 ③visibilitychange(탭 이탈) 시점 3가지로 묶어서 저장. 중간 조작은 클라 메모리에만.
  • 오프라인 진행은 서버 시각 기준. 클라 Date.now()를 믿으면 시계 조작으로 무한 자원. 마지막 저장 시각을 서버에 두고 lastSeenAt 차이를 서버에서 계산.
  • 반복 로직은 $roomTick(deltaMillis, roomId). setTimeout/setInterval 사용 금지가 문서에 명시. 다만 싱글 저장형은 룸이 필요 없음 — 성장·생산은 "접속 시 경과시간으로 한 번에 계산"하는 방식이 더 싸고 안전. 아래 10개 중 룸이 필요한 후보는 없음.
  • server.js 형식 고정: 루트에 server.js, class Server { }, export 금지. 클래스 변수는 요청마다 초기화되므로 상수 용도로만.
  • 세이브 검증: 클라가 보낸 상태 전체를 그대로 신뢰하지 말 것. 저장형은 자원 수치가 곧 게임이라, 서버에서 최소한의 정합성 검사(음수 금지, 시간당 최대 증가량 상한)를 넣는 편이 안전.
  • 스택 전제 확정: npm create vite@latest my-app -- --template react-ts + npm install @agent8/gameserver, 배포 npx -y @agent8/deploy.
라이선스 재확인 / 제외 — Quaternius는 공식 라이선스가 CC0가 아닌 커스텀 QAL(재배포 금지, 저작권 보유)이라 전면 제외. Pixel Frog(Tiny Swords) 커스텀, game-icons.net CC BY, LPC CC-BY-SA 제외. 아래 10개에 쓰인 에셋은 전부 원본 페이지 라이선스 표기를 직접 확인한 CC0.

에셋→게임 도출
Nature Kit 330개는 "지형을 코드로 흩뿌리면 섬이 완성된다"는 뜻이다. 여기에 Survival Kit의 도구·자원·캠프 구조물이 붙으면 채집 → 제작 → 건설이라는 사슬이 그대로 나온다. 자원 모델과 완성품 모델이 한 팩 안에 같이 있는 구성이라 제작 트리를 에셋만으로 설계할 수 있다.
Core Loop

WASD 이동 + 마우스 시점 + 클릭 상호작용
모바일 조작

12. 최종 추천

가장 빠르게 제작 가능 07 CRAWL COMPENDIUM — 캔버스도 3D도 물리도 없는 순수 DOM. 턴제라 프레임 루프조차 필요 없고, 저장 시점이 스테이지 단위라 세이브 설계가 가장 단순하다. 그런데 플레이타임은 10개 중 가장 길다.
에셋 완성도가 가장 높음 07(2D, 3,000+ 타일) / 02 HEX KINGDOM(3D, 건물 4색 배리에이션 200+) / 01 MINI DINER(음식 모델 200개). 셋 다 "그래픽이 먼저 바닥나지 않는" 조합.
추가 에셋이 가장 적게 필요 02 HEX KINGDOM — 지형·건물·자연 프롭이 한 팩에 동일 스타일로 들어 있고 아틀라스 1장이라 색·톤 보정조차 필요 없다.
모바일에 가장 적합 05 TINY FARM / 07 — 둘 다 탭만으로 완결되고, 세션을 5분에서 끊어도 손해가 없다. 저장형 + 모바일의 정석 조합.
플레이타임이 가장 길게 보장되는 게임 07 CRAWL COMPENDIUM (30~50h) — 도감 200종이라는 목표가 에셋 개수로 이미 확보되어 있음. 다음은 05 TINY FARM (20~40h)으로, 실시간 대기가 구조에 내장되어 있어 콘텐츠 대비 체류 시간이 가장 김.
Verse8 기능과 가장 잘 어울림 05 TINY FARM — 작물 성장을 plantedAt + 서버 시각으로 판정하는 구조가 Global User State와 Game Server를 정확히 문서 의도대로 쓴다. 시계 조작 방어와 오프라인 진행이 같은 코드로 해결되고, Ads(성장 즉시 완료)도 장르에 자연스럽다.
수익화까지 보면 01 MINI DINER가 Global User State + Ads + VXShop 세 개를 억지 없이 전부 쓴다.
전체적으로 가장 추천 01 MINI DINER — 이유 셋. (1) 이미 마음에 든다고 하신 방향이고, 저장형 기준에서도 v1 후보 중 유일하게 살아남을 만큼 구조가 맞다. (2) Food Kit 200모델이 곧 해금 트리라 플레이타임을 콘텐츠 제작 없이 확보한다. (3) Verse8 기능 매핑이 가장 자연스럽다 — 세이브는 Global User State, 오프라인 수익은 Game Server 시각 계산, Ads는 수익 2배, VXShop은 가게 스킨.

다만 더 빨리·더 길게가 목표라면 07 CRAWL COMPENDIUM이 객관적으로 우위(구현 난이도 ★★, 플레이타임 30~50h). 3D 비주얼이 중요하면 02 HEX KINGDOM, 가장 안전한 저장형 정석은 05 TINY FARM.
